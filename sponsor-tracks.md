## Best Use of the Factory Droid SDK
**Sponsor:** Factory

**Eligibility:** The project must use the Droid SDK (TypeScript or Python) in a meaningful way. Droid should do real work in the running product, not just help you write code. The repo README should explain where and how Droid is used.

**What scores well**
- Droid runs on a trigger you designed, like an event, a schedule, a user action, or another agent.
- Thoughtful control over what Droid can touch, with safety built in.
- Making Droid's work visible: plans, steps, diffs, and results.

**What scores poorly**
- A chatbot wrapper with Droid added on.
- Demos that only work in slides.
- Projects where we can't tell what the agent did.

**Prize:** $2,000 cash, Factory credits, and swag

## CRS Financial Intelligence Challenge
**Sponsor:** CRS Credit (Best Use of CRS Credit API)

**The only rule:** make meaningful use of the CRS sandbox and show it working live in your demo.

**Judging criteria**
1. **Use of CRS:** how central CRS data is to the product, not a bolt-on.
2. **Working demo:** it runs live against the sandbox.
3. **Usefulness:** it solves a real problem for a person or a business.
4. **Creativity:** it shows us something we didn't expect.

**Prizes**
- **Best Overall CRS Hack ($1,000 per team):** the most impressive product built on CRS.
- **Best Financial AI Agent ($500 per team):** an AI agent that does real work with CRS data, using the API or MCP server.
- **Best Identity / Fraud Innovation:** interview with the CRS team for an open forward-deployed engineer role, for each team member. The best project protecting consumers or businesses from fraud and identity theft.
- **Most Unexpected Use of CRS:** interview with the CRS team for an open forward-deployed engineer role, for each team member. The "we didn't think of this" prize.

**Getting started:** sandbox keys, docs and test identities are at https://calhacks.crscreditapi.com. Use the provided test identities only. Questions: find them at the CRS booth. They'll contact winning teams through Cal Hacks.

## The Hyphenated Enterprise: Autonomous Systems for Finance
**Sponsor:** Hyphenate

**Every submission is judged on the same four questions**
1. **Is it real enough?** Realistic data, a messy problem, and proof that it works.
2. **Would you hire it?** For which seats, and would it earn them: limited access, a clean record of its work, and knowing when to ask?
3. **Did we see something new?** A company, problem or approach we haven't seen made autonomous before.
4. **The moment.** When it catches what others missed, recovers from something going wrong, or defends a decision when questioned.

**Bring**
- A demo video that opens with your moment
- A live demo at judging (they may ask you to try a scenario of their own)
- One line on the seats your system fills
- Proof it works: what's real, what's simulated, and how you know

**More details:** CalHacks_Hyphenate_Track (sponsor doc)

**Prizes:** $8,000 / $5,000 / $3,000 for the top 3 teams; expedited interview process for the top 5 teams

## Best Use of Cartesia
**Sponsor:** Cartesia

Build a useful voice experience with Cartesia. Voice should be core to the product, not a feature added for the demo. Other tools are fine; make clear what Cartesia contributes.

**What to submit**
- A working demo
- A 2-minute, demo-first presentation: one complete user flow, then a brief problem + how you built it
- A short README: setup, Cartesia features used, known limitations
- Source access for judges (per event rules). No API keys or secrets in the repo

**Judging criteria (25% each)**
- **Problem and originality:** Useful, clearly scoped, thoughtfully designed?
- **Use of Cartesia:** Meaningfully integrated into the core experience? Voice clear, responsive, and natural?
- **Execution:** Main flow works? Likely edge cases handled?
- **Impact and responsibility:** Accessibility, privacy, and responsible use considered?

They'll favor a strong working prototype over a large unfinished idea.

**Ideas**
- Commute standup: voice-only morning brief you can interrupt while driving (hands-busy)
- Ambient / wearable assistant: help without pulling out a phone
- Keep-your-voice accessibility: clone for reading aloud or speaking another language
- Live coach or translator: low-latency back-and-forth where voice quality matters
- Multi-speaker agent: tutor, debate partner, or support sim with distinct voices

**Docs:** https://docs.cartesia.ai · **Playground:** https://play.cartesia.ai

**Prize:** Meta glasses (still TBD)

## Spacetime
**Sponsor:** Spacetime (SpacetimeDB)

They want projects where Spacetime is the core real-time backend, especially anything with live shared state, multiplayer interaction, or instant sync between users, agents, or systems. That fits games, and also chat/community apps, collaborative tools, social experiences, AI agent coordination, live dashboards, trading or financial-style apps, auctions and marketplaces, shared simulations, multiplayer productivity tools, and stream/creator tools. SpacetimeDB is built around real-time subscriptions, transactional updates, and server-side logic running close to the data.

**Example ideas:** a real-time portfolio sim, prediction market, collaborative trading game, shared ops dashboard, multi-user planning tool, or AI systems coordinating in a persistent world state. The main requirement is that SpacetimeDB is meaningfully used, not added on the side.

**Existing projects built with Spacetime**
- BitCraft Online / BitCraftPublic
- Elegon
- Pogly: a real-time collaborative stream overlay
- Official chat app tutorials/templates
- Video chat app

**Prizes:** 1st $2,048 · 2nd $1,024 · 3rd $512
